# JJS

Jonathan James Search website review prototype, imported unchanged from `JJS-Website-Mobile-Ready.zip`. Includes the Luke Banks proposed partner page and supplied photo, mobile styles, and homepage video.

## Preview locally

This is a static website with no build step or package dependencies. From the repository root, run:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000/>. Stop the server with Ctrl+C.

## Files

- `index.html`: homepage
- `about.html`, `services.html`, `expertise.html`, `methodology.html`, `candidates.html`, `contact.html`: main pages
- `luke-banks.html`: proposed retail industry partner profile
- Three CSS files and six supplied image/video assets sit alongside the pages. Keep the relative paths intact.

## Before launch

- The contact form is a preview only and does not send inquiries. Connect and test a form service or backend.
- Booking and direct email details still need to be connected.
- Luke Banks’s partnership, availability, biography, consulting offer, and project credentials remain subject to review and confirmation, as stated in the supplied pages.
- This import does not configure hosting, a domain, or automatic deployment. It preserves the supplied website without changing its content or design.
